# PDF Quick Edit — แก้ไข PDF ง่ายๆ ในเบราว์เซอร์

เครื่องมือเว็บสำหรับ **แก้ข้อความในไฟล์ PDF** แบบออฟไลน์ 100% — ไฟล์ไม่ออกจากเครื่อง ไม่ต้องติดตั้งอะไร ดับเบิลคลิก `index.html` ก็ใช้ได้

สร้างด้วย [pdf.js](https://mozilla.github.io/pdf.js/) (แสดงผล/หาตำแหน่งข้อความ) + [pdf-lib](https://pdf-lib.js.org/) (สร้างไฟล์ใหม่) + ฟอนต์ [Sarabun](https://github.com/google/fonts/tree/main/ofl/sarabun) (SIL OFL)

---

## เริ่มต้นใช้งาน

1. เปิดโฟลเดอร์นี้ด้วยเว็บเบราว์เซอร์ (Chrome / Edge / Firefox)
   - **ดับเบิลคลิก `index.html` ได้ทันที** — ไลบรารีทั้งหมดอยู่ในโฟลเดอร์ `lib/` ไม่ต่ออินเทอร์เน็ต
2. เปิดไฟล์ PDF (ปุ่มบน หรือลาก-วางลงบนหน้า)
3. เลือกวิธีแก้ 2 แบบ:

| โหมด | วิธีใช้ | เหมาะกับ |
|------|---------|----------|
| **คลิก/ค้นหาข้อความ** | ค้นหาคำ หรือคลิกบนข้อความในเอกสาร → พิมพ์ข้อความใหม่ → กด "เพิ่มการแก้ไข" | PDF ที่คัดลอกข้อความได้ (มาจาก Word/Excel/เว็บ) |
| **วาดกรอบเอง** | ลากเมาส์เป็นสี่เหลี่ยมบนหน้า → พิมพ์ข้อความใหม่ → เพิ่มการแก้ไข | **PDF ทุกชนิด** รวมไฟล์สแกนหรือตัวอักษรแสดงผลเพี้ยน |

4. ทำซ้ำได้หลายจุด หลายหน้า — ดูรายการทางซ้าย คลิกเพื่อไปหน้านั้น หรือลบทิ้งได้
5. กด **ดาวน์โหลด PDF ใหม่** → ได้ไฟล์ `ชื่อเดิม-edited.pdf`

> ไฟล์ต้นฉบับ **ไม่ถูกแก้ไขเลย** — สิ่งที่เกิดขึ้นคือกลบทับด้วยสี่เหลี่ยมขาว แล้ววาดข้อความใหม่ทับ (ฝังฟอนต์ Sarabun ในไฟล์ แสดงผลถูกต้องทุกเครื่อง)

---

## ข้อจำกัดที่ควรรู้ (ความจริงใจ)

- **ไม่ใช่การแก้ทีละตัวอักษร** เหมือนโปรแกรมสำนักงาน — เป็นการ "กลบแล้วพิมพ์ใหม่ทับ" ข้อความรอบข้างจะไม่เลื่อนตาม ถ้าคำใหม่ยาวกว่าเดิมมาก อาจเลยพื้นที่เดิม (ระบบจะย่อขนาดฟอนต์อัตโนมัติให้พอดีกรอบ)
- **PDF ที่มีรหัสผ่าน** ต้องนำออกก่อน (เปิด-บันทึกใหม่ด้วย Acrobat/โปรแกรมอื่น)
- **ตารางและแบบฟอร์มซับซ้อน** อาจต้องวาดกรอบทีละช่อง
- ผลลัพธ์ตรวจสอบด้วยการเปิดดูใน Acrobat / เบราว์เซอร์ ว่าถูกต้องก่อนใช้งานจริง

## โครงสร้างไฟล์

```
pdf-quick-edit/
├── index.html          # หน้าเว็บหลัก
├── style.css           # ธีม + เลย์เอาต์ (มือถือก็ใช้ได้)
├── app.js              # ตรรกะทั้งหมด: เปิด/แสดง PDF, 2 โหมดแก้ไข, save
├── _selftest.html      # เครื่องมือทดสอบตัวเอง (เปิดในเบราว์เซอร์ จะรายงานผลใต้หน้า)
└── lib/                # ไลบรารี localize — ใช้ออฟไลน์ 100%
    ├── pdf.min.js          # pdf.js 3.11.174 (แสดงผล)
    ├── pdf.worker.min.js
    ├── pdf-lib.min.js      # pdf-lib 1.17.1 (สร้างไฟล์ใหม่)
    ├── fontkit.umd.min.js  # ให้ pdf-lib ฝังฟอนต์กำหนดเองได้
    ├── sarabun-font.js     # ฟอนต์ Sarabun (base64) — ฝังมาเพื่อให้เปิดผ่าน file:// ได้
    └── Sarabun-Regular.ttf # ต้นฉบับฟอนต์ (SIL OFL) — ใช้สร้าง base64
```

> **ทำไมฟอนต์ต้องเป็น base64?** เพราะเปิดแบบดับเบิลคลิก (`file://`) เบราว์เซอร์ห้าม `fetch()` ไฟล์ในเครื่อง — ถ้าโหลดแบบ fetch จะพังตอนกดดาวน์โหลด (ฝัง base64 จึงเลี่ยงปัญหานี้)


## โอนย้ายไปใช้ที่อื่น

คัดลอกทั้งโฟลเดอร์ไปแฟลชไดรฟ์ / OneDrive / เครื่องที่ทำงาน → เปิด `index.html` → ใช้ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
